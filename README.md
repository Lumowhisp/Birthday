# 🎂 Birthday Website for Mom 🎉

This is a simple and heartfelt birthday website I built as a beginner to surprise my mom on her special day.

## 🌟 Features

- 🎉 Beautiful birthday message
- 📸 Photos & memories (if added)
- 🎵 Optional background music (if added)
- 💌 Personal touch, handmade with ❤️
- 🎨 Colorful design and animations (basic CSS/JS)

## 📚 Built With

- HTML
- CSS
- JavaScript

## 💡 What I Learned

- Creating structure using HTML
- Styling with CSS
- Adding interactions using JS
- Hosting and pushing code to GitHub

## 🧠 Motivation

This was my first real-world project — not for marks or assignments —  
just pure love and the joy of surprising my mom.
